# Questions for the Start-Up SCRUM

1. Which pages and user journeys must be demonstrated at the Sprint 1 review?
2. What product types and fields are defined by the supplied database?
3. Must the team use the supplied database technology unchanged, or may it be migrated?
4. What exact read-only information should an Employee be allowed to view?
5. Can Administrators deactivate users, change roles, and archive products, or only edit them?
6. Is guest checkout expected, or must Customers register before using a cart?
7. Which accessibility standard or testing evidence is expected for assessment?
8. Are wireframes in Markdown acceptable, or is a visual design tool required?
9. How should individual contribution evidence be submitted and verified?
